# Security

## Report a problem privately

If you find a security problem in Apel, please don’t open a public issue. Report it privately on GitHub with
[Report a vulnerability](https://github.com/erkanw/apel-agent/security/advisories/new). Say what you found, how to
reproduce it and which version you used (Settings → About shows it).

You’ll get an answer on the report. Fixes ship as a new release, and the advisory credits you unless you’d rather it
didn’t.

## Which versions get fixes

Only the latest release. Please update before you report, in case it’s already fixed.
